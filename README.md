mend applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files, every file changed or none. It matches old lines exactly or fuzzily, in three tiers, and reports each failed edit instead of failing the whole patch.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```
